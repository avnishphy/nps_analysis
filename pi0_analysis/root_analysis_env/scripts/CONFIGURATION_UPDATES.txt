PHYSICS METHODOLOGY IMPROVEMENTS
===============================================================================

TWO-STAGE OPTIMIZATION (Now Default)
-------------------------------------
Stage 1: Position Smearing Calibration
  - Observable: M_γγ only
  - Parameters: sigma_pos
  - Physics: Position uncertainty → direction uncertainty → angle smearing
  - Result: Calibrates angular resolution independently

Stage 2: Energy Smearing Calibration  
  - Observable: Both M_γγ and M_miss (controlled by ENERGY_SMEARING_HISTOGRAM)
  - Parameters: mu, sigma (with fixed sigma_pos from Stage 1)
  - Physics: 
    * M_miss constrains total photon energy (E₁+E₂)
    * M_γγ constrains energy product (E₁×E₂) and validated angle
  - Result: Fully constrained kinematics with decoupled systematics

WHY THIS IS BETTER THAN SIMULTANEOUS
-------------------------------------
1. Physically motivated: Position and energy have different detector origins
2. Better convergence: 1D then 2D scan vs 3D scan
3. Clearer diagnostics: Can identify position vs energy resolution issues
4. Faster: Reduced parameter space in each stage

COMBINED OBSERVABLE FITTING (Maintained as Default)
---------------------------------------------------
Using both M_γγ and M_miss simultaneously:
  - M_miss is sensitive to: E₁+E₂ (energy sum)
  - M_γγ is sensitive to: E₁×E₂ (energy product) and θ (angle)
  
This combination provides complete kinematic constraints.

WARNING: M_miss-only fitting (option 2) will optimize the energy sum but
         leave the energy asymmetry distribution unconstrained, resulting
         in good M_miss but poor M_γγ agreement. See detailed explanation 
         in MISSING_MASS_FITTING_ISSUE.txt

===============================================================================
RECOMMENDED WORKFLOW FOR USERS
===============================================================================

1. STANDARD CALIBRATION (Most Users)
   ----------------------------------
   Use the default settings (now optimal):
   - No changes needed!
   - Run with current configuration
   - Review chi2_scans.pdf to verify convergence
   - Check chi2/ndf < 2.0 for all sections

2. QUICK ENERGY-ONLY STUDY (Not Recommended for Final Analysis)
   ------------------------------------------------------------
   If you need a fast preliminary scan:
   - Set ENABLE_POSITION_SMEARING = false
   - Keep ENERGY_SMEARING_HISTOGRAM = 0
   - Be aware: This omits angular resolution calibration

3. DEBUGGING POOR FITS
   -------------------
   If chi2/ndf > 2.0 for many sections:
   - Check MIN_EVENTS_PER_SECTION (need sufficient statistics)
   - Verify data and simulation use same cuts (see simc_pi0_analysis.C)
   - Consider expanding MU_MIN/MU_MAX or SIGMA_MIN/SIGMA_MAX ranges
   - Check if resolution model is appropriate (try 3-term model)

4. ADVANCED: WEIGHTED OBSERVABLE FITTING
   -------------------------------------
   Only adjust W_MPI0 and W_MMISS if you have specific reasons:
   - Higher W_MMISS: If M_miss is known to be more precisely calibrated
   - Higher W_MPI0: If M_γγ has superior statistics or precision
   - For most analyses: Keep W_MPI0 = W_MMISS = 1.0

SCAN RANGES (Updated for Typical NPS Performance)
--------------------------------------------------
Energy scale (mu):
  - Range: 0.98 to 1.05 (was 1.015 to 1.04)
  - Steps: 70 (was 60)
  - Justification: Allows 2-5% corrections typical for calibrated detectors

Energy resolution (sigma):
  - Simple model: 0.015 to 0.08 GeV^(1/2) (was 0.01 to 0.09)
  - Steps: 65 (was 60)
  - Justification: NPS PbWO4 typical range, finer sampling

Position resolution (sigma_pos):
  - Range: 0.0 to 0.3 cm (was 0.0 to 0.2)
  - Steps: 30 (unchanged)
  - Justification: NPS ~0.5-1.5 cm typical, allow broader range

QUALITY CONTROL (Relaxed Threshold)
------------------------------------
MAX_CHI2_PER_NDF: 2.0 (was 0.8)
  - 0.8 was too strict (would flag many acceptable fits)
  - 2.0 is a reasonable warning threshold
  - Values 0.8-1.2: excellent agreement
  - Values 1.2-2.0: good agreement
  - Values > 2.0: investigate systematics or statistics
