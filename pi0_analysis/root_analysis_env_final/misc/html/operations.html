1. Load the Hall C environment

Run ROOT commands through csh after sourcing the module initialization and experiment setup:

cd /w/hallc-scshelf2102/nps/singhav/nps_analysis/pi0_analysis/root_analysis_env_main
csh -c 'source /usr/share/Modules/init/csh; source /group/nps/singhav/setup.csh; root-config --version'

A ROOT version confirms the environment loaded. Documentation inspection and this static website do not require ROOT.

2. Safest first execution: one run

cd /w/hallc-scshelf2102/nps/singhav/nps_analysis/pi0_analysis/root_analysis_env_main

bash src/analysis/run_parallel_nps_analysis_main.sh \
  --kin KinC_x60_4b \
  --run 4253 \
  --source waveform \
  --gevnum-cut no \
  --jobs 1 \
  --types production,Production \
  --no-combine

Check output/KinC_x60_4b/logs/analysis_main_run4253.log, the per-run summary, plots and diagnostics ROOT before scaling to a batch.

6. Proportional validation

Fast checks

python3 -m py_compile src/analysis/combine_analysis_branches.py
git diff --check

Extraction closures

csh -c 'source /usr/share/Modules/init/csh; \
source /group/nps/singhav/setup.csh; \
bash tests/run_xsec_tests.sh'

csh -c 'source /usr/share/Modules/init/csh; \
source /group/nps/singhav/setup.csh; \
bash tests/run_simc_phi_average_tests.sh'

Use the smallest representative sample first. A successful syntax check verifies parsing; a closure test verifies recovery under its synthetic assumptions; neither independently validates the real detector model.

7. Common failure modes

SymptomLikely cause / action
No runs matchedWhitespace or selection mismatch in master CSV. Inspect normalized fields and chosen types/target/quality.
Unresolved AcceptanceCutsThe driver must preload acceptance_cuts.cpp before the macro.
Combine reports missing metadataCreate output/efficiency_stuff/efficiency_<kin>.csv first or pass an explicit path.
Smearing exits before fitInput/config/provenance validation failed. Do not reuse prior outputs; inspect the current staging log.
Response fit rank failureUnsupported truth coefficient, sparse binning or degenerate angular support. Do not conceal it with an arbitrary pseudocount.
W<2 GeV in SIMC-model extractorThe local high-W evaluator has no MAID implementation and rejects this region.
