How SIMC calculates exclusive π⁰ electroproduction

An implementation-level reading of physics_pion.f, including the active 2021 charged-pion proxy, low-W MAID blend, every dormant legacy model, the CM-to-lab Jacobian, virtual-photon flux, and downstream channel factors.

1. Essential result

Most important finding

The high-W π⁰ calculation is not a fit to exclusive π⁰ data. When doing_pizero=.true., the active 2021 parameterization evaluates its π⁺ and π⁻ fits with the pion-pole factor set to zero, then returns their arithmetic mean:

σπ⁰,2021 = ½ [ σfit,π⁺(fπ=0) + σfit,π⁻(fπ=0) ].

This statement follows directly from lines 788–793. The file itself labels it “first pass, average of pi+ and pi-.”

The final function peepi returns a five-fold cross section in μb/MeV/sr². It starts from a model in μb/MeV²/rad, applies a full CM→lab Jacobian, then multiplies by a Hand-like virtual-photon flux and a moving-nucleon correction.

Which π⁰ nucleon? At low W, which_pion=0 uses MAID π⁰p and which_pion=1 or 3 uses MAID π⁰n. At high W, the π⁰ proxy ignores which_pion: proton and neutron receive the same averaged charged-pion fit before any later channel scaling.

2. Exact execution path

event.f:1459 calls main%sigcc = peepi(vertex,main).
physics_pion.f:45–53 calls transform_to_cm to boost the event and calculate θ*, φ*, q*, p*π, and the full Jacobian.
physics_pion.f:77–84 calculates s from the virtual photon plus struck nucleon and sets WCM=√s.
physics_pion.f:126–127 always evaluates sig_param_2021.
physics_pion.f:132–154 if W<2 GeV, also evaluates sigmaid (MAID table) and blends it into the 2021 result.
physics_pion.f:186–191 multiplies the model by the Jacobian, virtual-photon flux, and moving-target correction.
event.f:1460–1494 optionally multiplies Δ-final-state π⁰ channels by empirical factors after peepi returns.

An older multipole model, three older high-W fits, an alternate equivalent-photon definition, and an older MAID transition remain comment-disabled. Section 5 traces all of them.

For Fermi momentum magnitude pF, direction cosine cFq=p̂F·q̂, and struck-nucleon energy EF, the file computes:

s = (ν + EF)² − (|q| + pFcFq)² − pF²(1−cFq²),   WCM=√s.

For a free stationary proton this reduces to s=Mp²+2Mpν−Q². For bound targets, EF is off-shell: the target mass minus the on-shell spectator energy (event.f:362–371).

The π⁰ mass used during event kinematics is exactly Mpi0=134.9766 MeV. The active 2021 fit itself does not explicitly use mπ⁰; its effects enter through event kinematics, t, and the Jacobian.

4. Active 2021 model and the π⁰ proxy

sig_param_2021 stores two 17-parameter vectors: pp for π⁺ and pm for π⁻. For π⁰ it calls exclfit twice with fpifact=0.0.

4.1 Response equations exactly as coded

Let u=|t|, Q=Q² (despite the short name), S=s=W², and P=(p₁,…,p₁₇). exclfit calculates:

fπ = ffactor / (1+p₁Q+p₂Q²)
A = Q fπ²

σL = (p₃+p₁₅/Q) · u/(u+0.02)² · A · exp(p₄u) / [Sp₁₁+(√S)p₁₇]
σT = (p₅/Q) · exp(p₆Q²) · exp(p₁₄u) / [Sp₁₂+(√S)p₁₆]
σLT = [p₇/(1+p₁₀Q)] · exp(p₈u) · sinθ* / Sp₁₃
σTT = [p₉/(1+Q)] · exp(−7u) · sin²θ*
π⁰ consequence: f_factor=0 makes fπ=A=σL=0 for ordinary nonzero Q². σT, σLT, and σTT remain those of each charged-pion fit.

4.2 Azimuthal combination and normalization

σ219 = σT + εσL + ε cos(2φ*)σTT + √[2ε(1+ε)] cosφ* σLT

F(P) = σ219 · 8.539/(S−0.938²)² · 1/(2π·10⁶)

σπ⁰,2021 = [F(P+)+F(P−)]/2.

The returned unit documented by the code is d²σ/(dt dφ*) in μb/MeV²/rad. The hard-coded nucleon mass in this normalization is 0.938 GeV, for both proton and neutron.

5. Every dormant model and alternative in the file

π⁰ applicability audit

None of the three dormant analytic fits, nor the dormant multipole routine, implements a neutral-pion amplitude. They predate the doing_pizero argument. If a dormant call were restored, a π⁰ job would be routed through charged-pion logic according to which_pion. They are included here because they are physically relevant alternatives present in physics_pion.f, but they must not be described as π⁰ models.

5.1 Dormant sig_blok (lines 404–465)

The source identifies this as a Brauel et al. π⁺ fit with π⁻ modifications “by hand.” With u=|t|:

σL0=27.8e−11.5u,   σT0=50u e−5u,   σLT=0,
σTT0=−(4σL0+0.5σT0)sin²θ*.

fπ=[1+1.65Q+0.5Q²]−1,
σL=σL0(Qfπ²)/0.1215,   σT=σT0/(0.3+Q),   σTT=σTT0/(0.3+Q).

For the π⁻ branch only, σT and σTT are additionally multiplied by ¼(1+3e−10u); σL is unchanged. The routine forms the standard T+εL+TT+LT azimuthal sum and returns

σBlok=σsum · 15.333/(S−Mstruck²)² · 1/(2π·10⁶).

mrho_emp=0.712 is assigned but never used.

5.2 Dormant sig_param04 (lines 467–516)

This fit is described as reproducing Fπ-1 and behaving at larger Q². The expressions preserve the code’s signed t wherever it does not call abs:

fπ=[1+1.77Q+0.05Q²]−1,   R=u/(u−0.02)²,
σL=350Qfπ² exp[(16−7.5lnQ)(−t)],
σT=4.5/Q+2.0/Q²,
σLT={exp[0.79−(3.4/√Q)t]+1.1−3.6/Q²}sinθ*,
σTT=−(5/Q²)R sin²θ*.

The π⁻ branch multiplies only T and TT by ¼(1+3e−10u). After the common azimuthal sum:

σparam04=σsum · 8.539/(S−Mstruck²)² · 1/(2π·10⁶).
Literal-code detail: the pole factor is abs(t)/(abs(t)-0.02)**2, with a minus sign in the denominator. This creates a pole at |t|=0.02; the later fits use +0.02.

5.3 Dormant sig_param_3000 (lines 519–573)

This fit is documented as covering Fπ-1, Fπ-2, Brauel separated data, and Bebek unseparated data:

fπ=[1+1.77Q+0.12Q²]−1,
σL=19.8 · u/(u+0.02)² · Qfπ² · e−3.66u,
σT=(5.96/Q)e−0.013Q²,
σLT=[16.533/(1+Q)]e−5.1437usinθ*,
σTT=[−178.06/(1+Q)]e−7.1381usin²θ*.

Again, π⁻ multiplies only T and TT by ¼(1+3e−10u). Its final normalization is identical to param04:

σparam3000=σsum · 8.539/(S−Mstruck²)² · 1/(2π·10⁶).

5.4 Dormant low-W multipole model (lines 94–107, 156–163, 197–398)

The routine explicitly says it calculates p(e,e′π⁺)n; it also contains Clebsch–Gordan coefficients for π⁻p. It reads MULTIPOL.file, containing seven complex multipoles at 8 Q² points × 10 equivalent-photon-energy points × 3 isospins. It bilinearly interpolates each isospin amplitude:

A12=[A₁(QH−Q)+A₂(Q−QL)]/(QH−QL),
A34=[A₃(QH−Q)+A₄(Q−QL)]/(QH−QL),
A=[A12(νH−ν)+A34(ν−νL)]/(νH−νL),
amultipole= (197.327/mh) ΣI=1..3C(final,I)AI.

The seven entries are E0+, M1−, E1+, M1+, S0+, S1−, and S1+. The charge-channel coefficient rows are:

C(π⁺n)=(√2, √2/3, −√2/3),   C(π⁻p)=(√2, −√2/3, √2/3).

With c=cosθ*, sθ=sinθ*, c½=cos(θ*/2), and s½=sin(θ*/2), it constructs CGLN terms:

F₁=a₁+3c(a₄+a₃),   F₂=2a₄+a₂,   F₃=3(a₃−a₄),   F₄=0,
F₇=a₆−2a₇,   F₈=a₅+6ca₇,
H₅=−c½(F₇+F₈),   H₆=−s½(F₇−F₈),
H₄=[2s½(F₁+F₂)+c½sθ(F₃+F₄)]/√2,
H₂=[−2c½(F₁−F₂)+s½sθ(F₃−F₄)]/√2,
H₁=−c½sθ(F₃+F₄)/√2,   H₃=−s½sθ(F₃−F₄)/√2.

It converts these to Bartl amplitudes, then response bilinears:

hn⊥=(H₄+H₁)/√2, hf∥=(H₃+H₂)/√2, hn∥=(H₄−H₁)/√2, hf⊥=(H₃−H₂)/√2, hnL=H₅, hfL=H₆,
XT=|hn⊥|²+|hf∥|²+|hn∥|²+|hf⊥|²,
XL=|hnL|²+|hfL|²,
XTT=|hn∥|²+|hf⊥|²−|hn⊥|²−|hf∥|²,
XLT=hnLhn∥*+hfLhf∥*.

The kinematic factor and responses are:

K=2[(EF−pFcFq)/1000]√S[p*π/1000] / [(S−M²)M],
σT=KXT/2,   σL=KXL,   σTT=KXTT/2,   σLT=K Re(XLT).

The usual azimuthal sum is divided by 2 p*π q*. In the disabled top-level setup, this model would turn on only if k_eq<500 MeV on the first call, and k_eq≥500 is clamped to 499.9 inside the routine. The strict interpolation tests exclude points exactly on table boundaries. These are implementation facts, not recommended behavior.

Restoration is not one-line safe. The old sig_blok call contains ntup.sigcm1 instead of ntup%sigcm1, 1%e6 instead of 1.e6, and main.epsilon instead of main%epsilon. The disabled multipole setup also includes a disabled DATA low_w_flag/.FALSE./ initializer. These dormant paths require a deliberate code repair and validation, not mere uncommenting.

5.5 Commented alternative transitions and flux choice

Older MAID join

The current W<2.0 GeV gate and 1.5→1.9 blend replaced these two commented lines:

if W<2.3 GeV:   aold=max[0,(W−1.7)/0.6],   σ=aoldσhigh+(1−aold)σMAID.

Thus the dormant version would be 100% MAID through 1.7 GeV, linearly blend to 100% high-W model at 2.3 GeV, and (because no upper clamp appears in the old factor) rely on the W<2.3 gate to keep a<1.

Moving-target equivalent photon energy

The active choice uses the struck mass in its denominator. The commented DJG 2000 expression instead uses the moving nucleon’s q-axis flux combination:

keq,active=(S−M²)/(2M),   keq,dormant=(S−M²)/[2(EF−pFcFq)].

6. Low-W MAID table and blending

When W<2.0 GeV, peepi calls sigmaid. That routine reads four external tables once; π⁰ uses maidpi0p.dat for ipi=1 or maidpi0n.dat for ipi=2.

5.1 Table selection—no interpolation

iQ = clamp(INT[(Q²+0.1)/0.2], 1, 25)
iW = clamp(INT[(W−1.090)/0.020], 1, 46)
iθ = one of six explicit cosθ* intervals, then clamped to [1,6].

The six cosθ* intervals are [−0.20,0.20], [0.20,0.44], [0.44,0.63], [0.63,0.78], [0.78,0.90], and [0.90,1.00]. Boundary values can be overwritten by the later interval because the loop does not stop. Although the table array’s angular dimension is 23, this code accesses only indices 1–6.

5.2 MAID unpolarized cross section

It recomputes ε from W, Q², beam energy E₀, and a fixed mass 0.9383 GeV:

ν=(W²−0.9383²+Q²)/(2·0.9383),   E′=E₀−ν,
se²=Q²/(4E₀E′),   ε={1+2(1+ν²/Q²)se²/(1−se²)}−1.

If W<1.08 GeV, ν>E₀, or se² is outside (0,1], it returns zero. Otherwise, with table entries Tj:

wfact=1 for W≤1.232; otherwise (W−1.132)/0.100
σT=T₁/[max(0.2,Q²)·wfact],   σL=T₂σT,   σLT=T₃σT,   σTT=T₄σT
σMAID,Ω*=σT+εσL+√[2ε(1+ε)]cosφ*σLT+εcos(2φ*)σTT.

This result is in μb/sr and is converted to the model’s t–φ* convention:

σMAID,tφ = σMAID,Ω* / (2 p*π q*)   [μb/MeV²/rad].

7. From model cross section to peepi

6.1 Full Jacobian

jacobians.f analytically differentiates t and φ* with respect to the lab pion variables cosθlab and φlab. Its returned factor is:

J = | (∂t/∂cosθlab)(∂φ*/∂φlab) − (∂t/∂φlab)(∂φ*/∂cosθlab) |.

This converts d²σ/(dt dφ*) to the lab pion solid-angle cross section. The implementation is the general non-collinear/Fermi-motion expression at jacobians.f:208–271; jac_old is saved diagnostically but not used in peepi.

6.2 Equivalent photon energy and flux

keq = (WCM²−Mstruck²)/(2Mstruck)
Γ = [α/(2π²)] · (E′/E) · [keq/Q²] · 1/(1−ε),
CF = [1/(1−pF,zpF/EF)] · (Mstruck/EF).

Here α=1/137.0359895. Exactly as coded, pferz is the generated Fermi-direction z component in SIMC’s beam coordinate system; it is multiplied by the magnitude pfer. This differs from tfcos, the direction cosine along q.

6.3 Returned value

peepi = σmodel · J · Γ · CF
= d⁵σ/(dE′ dΩe′ dΩπ,lab)   in μb/MeV/sr².

For a stationary free nucleon, pF=0 and EF=M, so CF=1.

10. Reliability cautions visible in the implementation

  1. π⁰ is a proxy above the transition, not a dedicated fit. The source comment explicitly says the 2021 fit is to π⁺/π⁻ data.
  2. No validity range is enforced for the 2021 equations. Q²=0 is singular; fractional powers also require physical positive s. Extrapolation can yield unphysical or negative totals through interference.
  3. MAID lookup is stepwise. It clamps indices and performs no interpolation. The six-bin angular lookup accesses only the first six slots of a 23-slot table dimension.
  4. Two ε calculations coexist. The 2021 model uses main%epsilon from event kinematics; MAID recomputes ε with a fixed 0.9383 GeV mass and the supplied beam energy.
  5. The π⁰ scalar is averaged, but response bookkeeping is not. Because the π⁻ call occurs second, the /excmn/ common-block values sigl/sigt/sigttv/sigltv end as the π⁻ responses, not π⁰ averages. The returned scalar cross section is averaged correctly.
  6. Potential coordinate sensitivity in the moving-target flux correction. The comment describes a z component relevant to the collision flux, while the expression uses the beam-coordinate pferz*pfer; the invariant-mass calculation separately uses the q-axis projection tfcos. This page reports that literally and does not silently reinterpret it.
  7. The CM Jacobian has singular-looking analytic denominators at special geometries (for example sinθ→0). No explicit guards appear in the routine.
Reliability statement: The equations and branching above are reliable as a transcription of this exact source revision. Their phenomenological accuracy for NPS π⁰ kinematics cannot be established from code inspection alone; that requires validation against π⁰ data and event-level numerical tests.
