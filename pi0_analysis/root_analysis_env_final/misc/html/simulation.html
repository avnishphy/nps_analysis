SIMC, Geant4 and residual response smearing

The simulation carries a generated exclusive event through radiation, detector transport, reconstruction and calibrated residual response so data and Monte Carlo can be compared in the same reconstructed variables.

1. One reviewed row defines each setting

config/nps_simulation_kinematics.csv records beam energy, HMS momentum/angle, NPS angle/distance, SIMC event count, target/spectrometer offsets, Geant4 offsets, source run, template provenance and generation time. Existing calibrated offsets are preserved unless reset explicitly.

Why this matters. Geometry and offsets are no longer hidden in copied templates. The same reviewed row can generate SIMC infiles and parameterize wrapper commands, leaving a manifest of exactly what was run.

2. SIMC generates the interaction and radiative measure

SIMC samples the exclusive π⁰ reaction and carries the generator normalization, radiation, phase space and cross-section model. The relevant neutral pion decays isotropically to two photons. Generator products provide weights, vertex kinematics and normalization records used later.

Exclusive signal

γ*p→π⁰p is the principal channel. Separate SIDIS and Δ samples model physical backgrounds/components in detector comparisons.

Weight distinction

sigcm is the hadronic CM model factor. full_weight carries the larger generator/radiative/normalization measure. Their quotient is used by the response-fit extractor to remove the original hadronic prior while retaining simulated acceptance and normalization.

3. Geant4 transports both photons through NPS

The external detector simulation converts SIMC vertices and γγ kinematics into calorimeter deposits and reconstructed clusters. It preserves scalar event weights. Trigger/clustering thresholds and detector geometry determine which simulated photons become usable clusters.

Boundary of this repository. The staged repository orchestrates the SIMC/Geant4 chain through command templates and manifests; Geant4 internals are out of scope for the current refactor phase. Detector-threshold equivalence must still be demonstrated in physics validation.

4. The current high-W π⁰ cross-section prior

The inspected SIMC physics_pion.f does not contain an independent high-W π⁰ fit. Its active 2021 branch evaluates π⁺ and π⁻ parameterizations with the longitudinal pion-pole factor disabled, then averages their scalar cross sections:

σπ⁰,2021 = ½[σfit,π⁺(fπ=0) + σfit,π⁻(fπ=0)]

Below W=2 GeV, the generator blends toward MAID tables; the repository’s ported simc_pi0_model.h implements only the high-W branch and rejects W<2 GeV. It is used for the conventional ratio extractor’s model multiplier.

Do not over-interpret. This is a provisional charged-pion proxy. Setting the longitudinal pole term to zero in this implementation does not establish the physical statement σL(π⁰)=0.

5. Fit residual calorimeter response section by section

run_smearing_pipeline.sh produces a fresh nominal simulation, validates it, fits response parameters against combined data, builds an interpolated response map, reruns the producer in smeared-only mode from immutable raw inputs, then validates the final product.

E′ = response(E; μa, μb, μc, σ, …),   with optional position response
χ²/likelihood-like objective compares weighted data and replicated simulation mass shapes.

The active fast evaluator caches only parameter-invariant event quantities and deterministic random pulls. It cross-checks scalar-fast, batched-fast and legacy ROOT-histogram objectives; mismatch selects the legacy evaluator.

Nominal pass

Reconstruct raw simulation without residual smearing and validate required branches, entries and provenance.

Fit + map

Optimize response coefficients in spatial sections; write section_map.csv and interpolated ROOT maps.

Smeared replay

Replay the same immutable raw inputs using the accepted maps; require matching selected-entry count and provenance.

6. Staging and atomic publication prevent stale outputs

Every invocation uses a unique staging directory and hashed input snapshot. Producer, fitter and output validations must all succeed. Final files are published using same-directory temporary files plus atomic rename; a failed stage cannot masquerade as a successful current result by leaving old files in place.

output/<kin>/root/ ├── simc_pi0_analysis_output.root # current nominal ├── out_smear.root # fit diagnostics/state ├── section_map.csv # accepted section coefficients ├── interpolated_smearing_maps.root # producer lookup maps ├── simc_pi0_analysis_output_smeared.root # final replay ├── simc_smeared_2d_mass_cut.png/.pdf # final diagnostic └── smearing_runs/<run-tag>/... # immutable archive

7. Smearing is not automatically “detector resolution”

  • Mass shapes depend on the accepted physical pion-energy population, so model or channel-mixture errors can be absorbed into response coefficients.
  • Selection must be applied to the final smeared reconstructed event; preselection can miss inward/outward migration and pair changes.
  • Run-dependent dead masks and data/MC vertex/fiducial cuts must match.
  • The weighted objective is a useful discrepancy, but its nominal Poisson/HESSE interpretation is limited for efficiency- and purity-weighted shared events.
  • Residual smearing must represent response missing after Geant4, not double-count existing shower fluctuations and leakage.
