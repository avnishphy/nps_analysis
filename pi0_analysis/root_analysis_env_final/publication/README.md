# Publication products

Track definitions, schemas, reviewed source tables, figure scripts, concise
release manifests, and approved final artifacts here. Write regenerable draft
tables, plots, PDFs, covariance exports, and release candidates under ignored
`publication/generated/` until they are explicitly reviewed for release.

Every released result must identify its input/configuration/software
provenance, units, bin/coefficient ordering, interval convention, covariance
meaning, varied and held-fixed uncertainty sources, fit/replica diagnostics,
and production-validation status. No publication candidate exists yet.
