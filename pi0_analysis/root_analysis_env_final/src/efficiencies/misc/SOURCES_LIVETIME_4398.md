The catalog includes the user's May2025 luminosity work; Pooser/Mack Hall C
livetime and electronics studies; trigger drawings; SHMS draft; Murphy timing
study; Zhang/Raydo/Crafts NPS work; public issue history; user-supplied logs;
CODA/TI/TS manuals and APIs; local replay/hcana/NPSlib revisions and source
snapshots. Original PDFs, searchable text, retrieval metadata and hashes remain
available with the edition. Failed/unverified access is explicitly identified.

The user supplied [entry4170042, 2023-08-23](https://logbooks.jlab.org/entry/4170042)
and [entry4171556, 2023-08-29](https://logbooks.jlab.org/entry/4171556), then
confirmed applicability to these runs. Their text is preserved in
`livetime_complete_20260910/evidence/routing/`; original pages were not independently
retrieved after web authentication expired. This provides a working EDTM route,
superseding the older blanket statement that the route is unknown. It does not
establish detailed HMS fanout, the sent tap or PRE attribution.

Version and population limits matter. An updated hardware manual is not proof
of 2024 firmware behavior; a local source revision is not proof of the running
pass2 binary; an earlier PRE convention or empirical fit is not validation of
our trigger channels. CLT_physics is only a proposed definition and is never
used as a baseline. No new production correction follows from this catalog.

The old source collections remain frozen. Run their collection scripts only
for a deliberately separate source refresh, not to reproduce the issued
documentation: mutable online downloads would replace the preserved evidence.
