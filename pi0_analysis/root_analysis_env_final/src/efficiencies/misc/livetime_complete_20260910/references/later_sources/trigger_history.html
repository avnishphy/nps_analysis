Dec 2017

  • Dec 7 2017 : NIM modules for setting the pulse width of S1X,S1Y,S2X and S2Y before the HODO 3/4 trigger changed to 758 from 752 in SHMS and HMS Log Entry
  • Dec 8 2017 : HMS/SHMS HODO thresholds at 30mV. Log Entry
  • Dec 8 2017 : Oscilliscope pictures of HMS trigger using EDTM Log Entry
    • Note that this quickly changed and use later pictures.
  • Dec 8 2017 : Oscilliscope pictures of SHMS trigger using EDTM Log Entry
    • Note that this quickly changed and use later pictures.
  • Dec 12 2017 : Oscilliscope pictures of HMS trigger using beam. Log Entry
    • In HMS HODO 3of4 S1X is now sets the timing. All widths are 50ns.
    • In HMS EL_LO which is a 2/3 from PR_LO,STOF and HODO 3of4, the STOF sets the timing.
    • All other signal widths at 50ns.
  • Dec 19 2017 : Oscilliscope pictures of SHMS trigger using beam. Log Entry
    • In SHMS HODO 3of4 S1X is now sets the timing. All widths are 100ns.
    • In SHMS EL_LO which is a 2/3 from PR_LO,STOF and HODO 3of4, the STOF sets the timing.
    • All other signal widths at 50ns.
  • Dec 21 2017 : Oscilliscope pictures of SHMS/HMS coincidence using beam. Log Entry
    • Signal widths at 50ns.
    • HMS sets timing.
    • Elastic data with SHMS p = -1.816, theta = 25.01 and HMS p = +0.957, theta = 53.3

Jan-July 2018

  • The HMS triggers (when HMS single DAQ mode):
    • Trig1= HODO 3of4
    • Trig2 = EL_REAL
    • Trig3 = El_CLEAN
  • The SHMS triggers (when SHMS single and coin DAQ mode):
    • Trig1 = SHMS HODO 3of4
    • Trig2 =SHMS EL_REAL
    • Trig3 =SHMS El_CLEAN
    • Trig4 = HMS HODO 3of4
    • Trig5 not used
    • Trig6 = Coin SHMS HODO 3of4 && HMS HODO 3of4
  • Jan 10 2018 : Check SHMS/HMS gate widths at 50ns and thresholds at -30mV. Log Entry.
  • Jan 15 2018: Shift the STOF by 15ns in the SHMS and HMS EL_LO triggers. Log Entry
  • Jan 18 2018 : Adjusted HMS timing in the coincidence trigger for having both spectrometers with beta near 1. Log Entry
    • Oscilliscope picture of trigger. Log Entry
  • Jan 23 2018 : Removed the HMS STOF from reference time signal. Log Entry
    • SHMS STOF was also removed, though no logbook entry about it.
  • Feb 16 2018: Add cabling for the "6 GeV" electronic deadtime measurement.Log Entry.

Aug 2018

  • Aug 9 2018 : Removed El_CLEAN from SHMS/HMS reference time Log Entry
  • Aug 9 2018: In ROC03 and ROC06 the widths were 50 and 45 ns, respectively. Changed to 30 ns. Log Entry
  • Aug 9 2018: Replaced the SHMS Pulse shaper for the FADC reference time. Log Entry
  • Aug 13 2018: Replaced the SHMS Pulse shaper for the FADC reference time. Log Entry
  • Work done over the summer to adjust SHMS hodoscope cable lengths to compensate for the two different PMT types used in the hodoscope with different transit times.

Sept 2018

  • Added additional coincidence trigger as TRIG5. Changed SHMS TRIG3 to be HMS EL_REAL.
  • The HMS triggers (when HMS single DAQ mode):
    • Trig1= HODO 3of4
    • Trig2 = EL_REAL
    • Trig3 = EL_CLEAN
  • The SHMS triggers (when SHMS single and coin DAQ mode):
    • Trig1 = SHMS HODO 3of4
    • Trig2 = SHMS EL_REAL
    • Trig3 = HMS EL_REAL
    • Trig4 = HMS HODO 3of4
    • Trig5 = Coin SHMS HODO 3of4 && HMS EL_REAL
    • Trig6 = Coin SHMS HODO 3of4 && HMS HODO 3of4
  • Sept 27 2018: Check of the reference times Log Entry.
  • Sept 27 2018: Oscilliscope pictures of HMS trigger Log Entry.
    • All HMS signal width are 50ns.
    • For HMS EL_LO_LO , HMS HODO 3of4 takes timing.
  • Sept 27 2018: Oscilliscope pictures of SHMS and COIN trigger Log Entry.
    • All SHMS signal width are 50ns for triggers, except S1_OR and S2_OR going into STOF which looks like about 30ns.
    • For SHMS EL_LO_LO , SHMS HODO 3of4 takes timing.
    • For both coincidence triggers, the SHMS is 100ns wide and HMS is 60ns wide. With HMS setting the timing.
  • Oct 2 2018: Adjusted widths of SHMS/HMS coincidence signals for TRIG5. Oscilliscope pictures Log Entry.
    • SHMS Hodo 3of4 width reduced to 60ns.
    • HMS EL_REAL width reduced to 20ns
    • The TRIG6 is now SHMS Hodo 3of4 width of 60ns && HMS Hodo 3of4 width of 60ns.
  • Nov 27 2018: Polarity flip of the reference times. Log Entry.
    • This applies to post coincidence run 6576.
    • Made the coincidence time resolution was improved to match what was seen in Spring 18.
    • Detailed discussion Log Entry.

Feb 2019

  • Feb 2019 :DAQ changes for the J/Psi experimentLog Entry.
    • Noble Gas Cerenkov replaced the Heavy Gas Cerenkov in the SHMS EL_REAL
  • Feb 9 2019: Oscilliscope pictures of HMS trigger Log Entry.
  • Feb 9 2019: Oscilliscope pictures of SHMS trigger Log Entry.
  • Feb 9 2019: Oscilliscope pictures of Coin trigger Log Entry.
    • TRIG6 has SHMS Hodo 3of4 width of 60ns && HMS Hodo 3of4 width of 60ns.
  • Feb 9 2019: TRIG5 could possibly Coin SHMS HODO 3of4 && HMS EL_CLEAN Log Entry.
  • Mar 5 2019: DAQ reverted back to CSV and KAONLT setup Log Entry.
