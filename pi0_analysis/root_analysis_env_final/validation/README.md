# Validation

Track check definitions, small non-sensitive fixtures, prospective pass
criteria, and concise result summaries here. Write generated test products,
temporary builds, pseudoexperiments, and bounded-run outputs under ignored
`validation/runtime/`. A result summary must identify the exact command,
working directory, environment, inputs, configuration, implementation commit,
output location, measured result, failures, and interpretation.

No production or publication validation has passed merely because the baseline
copy is intact.
