Source-faithful browser calculator

Exclusive pion model explorer

Select one exact analytic branch from physics_pion.f, move through physical two-body kinematics, and inspect the φ, −t′ and Q² dependences without installing ROOT. Every calculation runs locally in this page.

Scope is explicit. The π⁰ choice is the active high-W 2021 proxy: the arithmetic mean of π⁺ and π⁻ fits with the pion-pole factor set to zero. The Blok, param04 and param_3000 choices are commented-out charged-pion branches—not independent π⁰ models. MAID and multipole branches require external tables and are documented below, but are not impersonated by an analytic curve.

How to read these curves

1. Choose the branch

The status chip distinguishes active code from historical routines that remain commented out. Charged branches are present for comparison, not relabeled as π⁰ physics.

2. Fix one physical point

Set Q², W, ε, −t′ and φ. With physical-angle mode enabled, the page computes θcm from exact two-body π⁰p kinematics.

3. Inspect or export

Hover over any curve for values. Download its sampled points as CSV for an independent plot or numerical cross-check.

d²σ/(dt dφ) = [σT + εσL + √(2ε(1+ε))σLTcosφ + εσTTcos2φ] / 2π

The analytic functions return μb/MeV²/rad. The page converts to nb/GeV²/rad by multiplying by 10⁹. The displayed response coefficients omit the explicit 1/(2π), matching the decomposition above.
