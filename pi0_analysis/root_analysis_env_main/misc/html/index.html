The measurement

Exclusive neutral-pion electroproduction

The channel is (e p → e′ p′ π⁰), followed by (π⁰ → γγ). HMS measures the scattered electron. NPS reconstructs the two photons. The recoil proton is inferred through missing mass.

1

Electron arm

HMS supplies the scattered-electron momentum and direction, defining (Q²), energy transfer ν, Bjorken (x_B), and the virtual-photon direction.

2

Photon calorimeter

NPS clusters electromagnetic showers. Two accepted clusters provide (E_1,E_2), directions, opening angle, and the reconstructed γγ four-vector.

3

Exclusive closure

The γγ invariant mass identifies π⁰ candidates; the missing mass (M_X(e p→e′γγX)) tests whether the unobserved state is a proton.

mγγ² = 2E₁E₂(1−cosθ₁₂)   ·   MX² = (pe+pp−pe′−pγ1−pγ2)²
Information flow

The detectors answer complementary questions

HMS: “What virtual photon was exchanged?”

Tracking, gas Čerenkov, calorimeter, hodoscope, trigger/scaler and beam-current information establish a clean electron sample and the exposure correction. Acceptance defaults include (|δ|≤10%), (|x′|≤0.1), (|y′|≤0.04), (|z|≤8) cm, NPE>4, and (0.8<E/p≤1.2).

NPS: “Is there a π⁰ compatible photon pair?”

Clusters are filtered by energy, position, timing and run-dependent dead-block masks, then paired. Global defaults use (E_gamma>1.5) GeV and the fiducial window x∈[−26,26] cm, y∈[−32,32] cm; KinC_x36_5 variants override the energy threshold to 1.6 GeV.

End-to-end map

One analysis, seven linked stages

01ConfigureRun table, kinematics, cuts, dead blocks
02Analyze runsHMS + NPS selection, pair physics, backgrounds
03Correct exposureCharge, prescale, livetime, tracking and hodoscope
04CombineAttach per-run scale and merge physics trees
05SimulateSIMC kinematics/radiation → Geant4 detector response
06Smear residualsFit section response; publish deterministic maps
07Extract σData/SIMC ratio or global migration-response fit

Stages are not interchangeable. The data tree carries reconstructed physics and a mass-based signal weight. The combined tree adds exposure corrections. Simulation supplies acceptance, migration, radiation and model information. Extraction finally connects corrected data yields to virtual-photon response coefficients.

Scientific status

What is established—and what remains conditional

Implemented and validated

  • Per-run data processing and explicit output contracts
  • Frozen efficiency/livetime stage and uncertainty columns
  • Deterministic smearing pipeline with staged validation and atomic publication
  • Conventional SIMC-model extraction and global response-fit extraction
  • Generated→reconstructed migration diagnostics and synthetic closure tests

Physics caveats remain

  • High-W π⁰ generator model is a provisional average of charged-pion fits
  • Residual smearing can be confounded with the accepted physics population
  • Data and MC reconstructed selections must remain genuinely equivalent
  • Radiative treatment for the neutral-pion channel needs a dedicated decision
  • Reported uncertainties omit several detector/model/radiative systematics
Interpretation rule. A pipeline that runs successfully has passed software and contract checks. That alone is not a complete physics validation. The site marks measured implementation facts, approximations and open physics decisions separately.
